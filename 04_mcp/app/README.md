# Travel Assistant App


## What this app combines

- [x] v1: basic Travel Assistant
- [x] v2: better prompt shape and supplied context
- [x] v3: tool-using assistant with routing
- [x] v4: MCP-inspired tool registry with `list_tools()` and `call_tool(...)`

## Exercise

- Your task is to add a new tool to `server.py`, register it in `get_server_info()`, and keep the MCP toolset discoverable.
- Update the `app.py` code to use the MCP toolset and `list_tools()` flow together.
